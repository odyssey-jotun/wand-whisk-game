Full-size standing art the game rigs are cut from. The game itself only loads the quarter-size pieces in assets/rig/.

- strawberry-stand.png: Strawberry, standing, facing right (made in ChatGPT from the cafe's art)
- matcha-stand.png: Matcha, standing, facing right (same)

cut_rig.py turns a standing image (white background removed) into the body, thigh and shin pieces,
plus an optional casting arm. The numbers for each girl live in the git log of this folder.
