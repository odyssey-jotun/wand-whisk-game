# Wand & Whisk: Milk Panic

One-level side scroller starring the four Wand & Whisk Cafe girls (Strawberry, Matcha, Ube, Creamia). The boss is Strawberry Milk the cow. Tap to shoot, hold to charge a special; enemies drop Health and Mana Floats.

Plain HTML5 canvas in a single `index.html`, no build step. Open it through any static server.

- Desktop: arrows or A/D to move, Space to jump, X to throw magic
- Phone: on-screen buttons, landscape

Character art in `assets/` belongs to Wand & Whisk Cafe (wandandwhiskcafe.com), used with the owner's permission.
